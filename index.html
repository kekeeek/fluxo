À propos de Fluxo

Fluxo est une interface indépendante. Elle n'héberge aucun fichier elle-même : chaque envoi passe par l'API publique de gofile.io, qui stocke réellement les fichiers sur ses serveurs. Les liens partagés depuis Fluxo passent par ce site pour rester courts et cohérents avec la marque Fluxo, puis redirigent vers le fichier hébergé.

Questions fréquentes

Où sont stockés les fichiers ?

Sur les serveurs de gofile.io, via son API publique. Voir la section "À propos" ci-dessus.

Pourquoi un lien fluxo au lieu d'un lien gofile ?

Pour que les liens partagés restent courts et à l'image de Fluxo. Techniquement, ce site se contente de rediriger immédiatement vers le fichier réel hébergé par gofile.

Est-ce gratuit ?

Oui. L'appli et ce site sont gratuits ; le stockage sous-jacent dépend des conditions de gofile (compte gratuit ou premium).

Fluxo n'est pas affilié à gofile.io. Fluxo est un client indépendant utilisant l'API publique de gofile.
